## Start an extraction

1. Confirm written authorisation to inspect the site or repository.
2. Capture the authorised URL or repository commit.
3. Run `npm run scan -- <repo> --out signals.json`.
4. Complete `examples/_template/DESIGN-DNA-AUDIT.md` with `file:line` evidence.
5. Build `design-dna.json` and validate it before scaffolding a skill.

Do not invent tokens, components, scores, testimonials, product claims, or brand facts.
